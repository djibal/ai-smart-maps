# ADR-0006: Temporal Data Lifecycle Architecture (TDLA)

- **Status:** proposed
- **Date:** 2026-09-24

## Context

Temporal layers with no retention policy cause unbounded storage growth and
query degradation.

## Decision

Four tiers: HOT (0–7 days, in-memory), WARM (7–90 days, SSD), COLD (90 days–2 years,
object storage), ARCHIVE (>2 years, compressed). Deletion policy: user data within
30 days on request; community reports anonymized after 90 days; mesh messages
never persisted.

## Consequences

- Bounded storage growth
- Predictable query latency per tier
- Requires tier-migration automation
