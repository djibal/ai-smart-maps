# ADR-0007: Confidence-Aware Offline Mode (CAOM)

- **Status:** proposed
- **Date:** 2026-09-24

## Context

Offline AI quality drops silently. Users do not know they are receiving degraded
routes. Safety risk.

## Decision

Every route and decision carries a confidence score derived from map data age,
community report density, model version, route novelty, and environmental
complexity. Below 60% confidence, warn the user and prefer known-safe roads.

## Consequences

- Transparency for degraded operation
- Requires confidence calibration per model version
- May reduce perceived performance when honest
