# ADR-0004: Zero-Trust Mesh Architecture (ZTMA)

- **Status:** proposed
- **Date:** 2026-09-24

## Context

BT mesh is vulnerable to Sybil, eclipse, replay, jamming, wormhole, and identity
spoofing attacks.

## Decision

Layered mitigations: proof-of-work for participation, multi-path routing, monotonic
sequence numbers with 50ms timestamp window, BLE 5.4 channel hopping, physical
plausibility checks, ephemeral keys rotating every 15 minutes.

## Consequences

- Robust against known mesh attacks
- Higher battery and CPU cost
- Requires hardware support for BLE 5.4 channel selection
