# ADR-0002: Decentralized Tile Federation (DTF)

- **Status:** proposed
- **Date:** 2026-09-24

## Context

The blueprint implies a centralized tile/graph server. Outage, DDoS, or
censorship causes global failure.

## Decision

Adopt content-addressed tiles with peer discovery. Any node can serve any tile.
Signed tiles prevent tampering. No central authority required for reads.

## Consequences

- Removes single point of failure
- Censorship-resistant
- Requires signing infrastructure and peer discovery protocol
- Adds complexity to tile versioning
