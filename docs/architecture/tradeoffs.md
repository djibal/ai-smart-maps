# Irreducible Trade-offs

| Choice | Gain | Loss |
|--------|------|------|
| On-device AI | Privacy, offline latency | Model quality, update velocity, device cost |
| Federated learning | Privacy, scale | Convergence speed, debugging difficulty |
| BT mesh | Offline safety | Battery, complexity, security surface |
| OSM base layer | Cost, openness | Freshness, completeness |
| Community data | Coverage, cost | Trust, validation load |
| Cross-platform | Reach | Performance parity, native feature access |
| Temporal layers | Rich context | Storage explosion, query complexity |

**Key Decision:** Privacy over model quality; offline over fresh. Correct strategic bet, requires architectural compensation.
